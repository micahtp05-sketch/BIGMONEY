Type scale

Step 3 — page title

Step 2 — section heading

Step 1 — subheading and lede

Step 0 — body copy, the default everywhere.

Each step is a clamp(), so the scale compresses on narrow screens without a media query. Resize the window to watch it move.

Prose and code

The .prose wrapper caps line length at --measure and spaces sibling elements automatically, so long-form pages need no per-element margins. 

.prose > * + * { margin-top: var(--space-4); }

Notes use the accent as a left rule against a subtle fill.
