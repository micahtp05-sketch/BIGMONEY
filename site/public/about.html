About

There is no product here, no company, and no story to tell yet. This site exists so that the moment there is one, none of the groundwork has to be argued about first.

What's already decided

A handful of choices are baked in, chosen to be the ones least likely to need undoing:

  • No build step. Files on disk are the files the browser gets.
  • No dependencies. The server is Node's http module and roughly seventy lines.
  • No framework. Adding one later is a choice; removing one is a migration.
  • Tokens over hard-coded values. The palette has a single source of truth.

What's deliberately missing

Analytics, a contact form, social links, cookie banners, and a content-management layer are all absent. Each of those is a decision that depends on what the site turns out to be, so none of them are pre-empted here.

Running it

cd site
npm start        # http://localhost:4000

There is nothing to install first. PORT and HOST are both read from the environment if you need to change them.
