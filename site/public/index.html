A website with no purpose.

This is scaffolding, not a product. Every page, colour, and word below is a placeholder held in place until this site is given something to say.

See the style guide What this is

No dependencies

Plain HTML, CSS, and JavaScript served by Node's built-in HTTP module. Nothing to install, nothing to upgrade, nothing to remove later.

Tokens first

Colour, type scale, spacing, and shape live as custom properties at the top of styles.css. Change them and the site follows.

Light and dark

Follows the visitor's system setting, with an explicit toggle that wins in both directions and survives a reload.

Accessible by default

Semantic landmarks, a skip link, visible focus rings, and reduced-motion handling are already wired in rather than retrofitted.

Giving it a purpose

When this site becomes something, the shape of the work is small and known. Nothing below requires a rewrite.

  1. Replace the name Untitled in each page's header, footer, and <title>.
  2. Set the palette and type scale in the token block at the top of styles.css.
  3. Rewrite this homepage around the actual thing. Delete the cards you don't need.
  4. Add pages as public/<name>.html — they resolve at /<name> automatically.

The style guide page renders the tokens live, so it doubles as a check that a palette change reads correctly in both themes before you commit to it.
